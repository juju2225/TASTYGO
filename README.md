# TASTYGO



TASTYGO est une application web dédiée à la découverte de recettes du monde.

L'application permet d'explorer des recettes provenant de différents pays, de rechercher des idées selon plusieurs critères et de consulter leurs informations détaillées.L'utilisateur peut également découvrir des recettes de manière aléatoire, enregistrer ses recettes favorites et générer une liste de courses à partir d'une recette.


TASTYGO a été conçu comme un projet de développement web permettant de mettre en pratique React, TypeScript et les différentes fonctionnalités d'une application front-end moderne, notamment la gestion des données provenant d'une API, la navigation entre les pages et la gestion des interactions utilisateur.


## Technologies

- React
- TypeScript
- Vite
- Bootstrap
- React Router
- TheMealDB API

## Fonctionnalités

- Rechercher des recettes
- Découvrir des recettes aléatoires
- Filtrer les recettes
- Consulter le détail d'une recette
- Ajouter des recettes aux favoris
- Gérer une liste de courses
